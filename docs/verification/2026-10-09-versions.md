# ContextHub 0.2.0 版本管理验收

日期：2026-10-09。实现分支：`feature/library-versions`。本阶段在可运行迁移 MVP 上加入版本历史、固定链接、Fork、编辑、整包更新与差异比较。

## 已验证结果

`python3 -m unittest discover -v`：**77 项通过**，包括原有 46 项迁移测试，以及新增的 16 项修订/差异测试、10 项存储测试和 5 项 HTTP 测试。

- 旧数据库中的公开和私有包幂等迁移为 v1，原 ID、字节、时间和 Git commit 保留。
- 固定版本读取、下载、历史与比较分别执行权限检查；跨库版本 ID 不可借用。
- 两个 Store 实例同时保存只有一个基准更新成功；另一方冲突，不丢失更新。同基准、内容和说明的成功重试返回原版本。
- 公开新版本具有真实 Git parent，公开 Fork 连接所选公开源版本；私有库及其 Fork 不进入 Git。
- 模拟 Git 写入失败、Git 对象写入后的 SQLite 失败，数据库 head/历史和 Git ref 不会前进；重启时可按数据库恢复 refs。
- Fork 修改独立于上游，上游删除后隐藏来源信息；独立副本继续可读。
- 修订保留来源和历史审计，人工改写由服务端记录；相同输入产生相同包字节。
- 差异按 ID 计算完整摘要，插入不把后续消息误判为移动；消息详情、文字与元数据均有显示上限，并明确标识截断。

## 浏览器验收

命令：

```bash
python3 scripts/verify_web.py
python3 scripts/verify_versions_web.py
node --check contexthub/static/app.js
node --check contexthub/static/versions.js
```

本环境通过 `PYTHONPATH=/tmp/contexthub-browser-libs` 加载可选 Playwright。两个脚本均通过，JavaScript 异常为 0。

原迁移流程回归覆盖上传预览、公开/私有包、精确下载、账号、搜索、刷新和连接器合成导出/导入。新流程使用两个真实临时 Hub 账号和 Chromium 验证：

1. Alice 上传公开对话库；Bob 从固定版本 Fork，默认私有选项可见并可明确选择公开。
2. Bob 编辑标题、上下文和正文，新增消息，先预览再发布 v2；Alice 原库保持不变。
3. 比较版本、选择 v1、刷新固定链接、下载 v1；下载字节与最初上传包完全一致。
4. 将新的 `.contextpack` 检查并应用为下一版候选，发布 v3；旧版继续可读。
5. 两个标签页基于 v3 编辑，先提交生成 v4；后提交收到 409，草稿保留且不能强行覆盖。
6. 延迟上游读取请求后开始编辑，旧响应到达不会替换新草稿。
7. 390px 手机宽度的历史阅读和差异界面无横向溢出。

截图与 JSON 报告保存在被忽略的 `.artifacts/`：`versions-reader.png`、`versions-diff.png`、`versions-mobile.png`、`versions-web-verification.json`。已实际检查桌面和手机截图。

## 独立审查与修复

审查用原始复现再次核验四项修复，确认无残留阻塞问题：

- 历史审计原样保留顺序和重复项，避免连续修改后无操作提交意外改变快照。
- 拒绝会在规范化中改变会话 ID 的修订输入，防止借原生 ID 别名绕过来源/人工编辑标记保护。
- 创建草稿时使旧 reader 请求失效，并保护异步返回后的页面切换。
- 展示消息元数据差异和移动标记；来源与审计 JSON 默认折叠，仍可展开检查。

## 本地交付

先停止旧开发服务，将现有 SQLite 索引备份到 `.artifacts/before-versions-20261009-113809/hub.sqlite3`，再使用原 `.context-data` 启动。包文件保持在原位置。当前 <http://127.0.0.1:8765> 的 `/api/config` 返回 `0.2.0`，主页及所有 JavaScript/CSS 资源均返回 200。

所有验收内容和账号均为临时合成数据，不向用户真实库添加演示记录；本阶段没有读取 Codex 私人对话或调用模型。Codex 原生 UI/真实模型续聊的兼容性范围没有扩大，沿用[迁移验收说明](2026-10-09-transfer.md)。

## 明确边界

库级公开/私有可见性固定；草稿仅浏览器内存，无服务器自动保存；Fork 复制一个所选快照和来源关系，不复制全部版本历史；来源关系存储于 Hub，不改写原下载包。当前没有贡献请求/合并、逐版本撤回或原生 Git push/clone 服务。删除仍是访问撤销，不进行底层 blob/Git 对象物理清除。
