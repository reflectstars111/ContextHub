## 首版边界

单分支完整快照；clone 取得所选版本，不镜像全部远程提交。尚无 branch、自动 merge/rebase、force/reset、对象 GC 或 Git wire protocol。CLI 原地改变可见性、贡献请求流程暂不提供；相关贡献操作继续使用网站。Fork 成功但下载中断时，可在网站找到已创建的副本后 clone，重复 fork 会创建另一份库。详细操作与恢复说明见 [ctx 指南](../cli.md)。
