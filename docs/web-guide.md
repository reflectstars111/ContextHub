# 网页使用指南

这里介绍网页上的阅读、编辑和协作。首次保存项目看 [README](../README.md)，终端操作看 [ctx 指南](cli.md)。

## 找到对话和对应代码

打开项目后，先选对话，再按日期选择轮次。页面只显示当前轮次，长对话会分页，也可以搜索正文或切换前后轮。没有时间记录的旧内容会显示“时间未记录”。

项目中的几个入口各有用途：

| 入口 | 用来做什么 |
| --- | --- |
| 对话 | 阅读开发过程，查看消息关联的代码 |
| 代码 | 浏览已保存的目录、文件和代码变化 |
| 版本历史 | 找到旧版本，比较版本之间的对话和代码变化 |
| 贡献请求 | 查看别人提交的改进，讨论并合并 |
| 设置 | 拥有者修改可见性或永久清理库 |

消息下的“采集时的代码”指向保存那次对话时的代码快照。点击后可浏览文件，再用“返回来源消息”回到对话。没有关联的消息会显示“未记录当时代码”；平台不会根据旧消息猜出当时的代码。

“导入与处理记录”表示格式转换、脱敏或人工编辑记录，代码修改要到“代码”或版本比较中查看。差异详情过长时会截断并提示，完整内容可登录后下载。

## 分享位置，或带到本机继续

- **复制当前位置**：分享所选轮次、分页或代码文件。刷新、前进和后退也能回到对应位置。
- **复制版本链接**：分享整版项目。两个链接都固定版本，后续更新不会改变链接所指的内容。
- **在本机 Codex 中继续**：选择新目录和终端类型，复制生成的命令到运行 Codex 的终端。步骤与限制见 [网页导入 Codex](cli.md#从网页一步导入本机-codex)。
- **恢复所选代码**：生成准确选择版本、消息或快照的 Bash 命令。未关联代码的轮次、未发布草稿和失效的旧式 Git 检查点不会提供恢复命令。

公开库可以匿名阅读；下载、上传、Fork 和修改需要登录。私有库只对拥有者开放，分享链接不会绕过权限。

## Fork 后修改，或更新自己的项目

1. 想复用别人的内容，先在“版本历史”选择版本，再点“Fork 到我的对话库”。默认创建私有副本；自己的项目可以直接进入下一步。
2. 切到自己库的最新版本，点“编辑副本”，修改标题、背景或消息，也可以新增、移除、移动消息。
3. 已有新版 `.contextpack` 时，可选“导入对话包作为下一版”。确认后它会替换整份草稿，不会自动拼接两段不同会话。
4. 填写保存说明，点“预览变化”，检查后保存。公开库的“发布新版本”会让新内容立即可被阅读和下载。

编辑会自动保存为仅自己可见的服务器草稿，刷新后可恢复。草稿还不是正式版本。若多个页面发生冲突，按提示处理，并可先下载本页备份；离开前留意保存状态。

Fork 复制所选版本并保留来源，不复制整个历史。你的修改只进入自己的库，不会改变原项目。原项目删除后，已创建的独立 Fork 仍保留。

## 把改进交给原作者

当前支持**公开 Fork 向其直接的公开上游**贡献。若希望贡献，创建 Fork 时选“公开分享”。

1. 在自己的 Fork 中保存改进后的版本，点“贡献给上游”，填写标题和说明。
2. 原作者打开贡献请求，阅读变化和讨论，点击“检查合并”。
3. 能合并时，原作者点击“查看本次合并变化”，确认内容后再点“合并并发布新版本”。

提案使用提交时选定的版本。之后修改 Fork，需要明确“更新提案版本”，才会纳入提案。原作者在检查后发布了新版，或提案版本发生变化，都需要重新检查和审阅。

双方可以评论、关闭或重新打开请求；已合并的请求不能重开。其他人可阅读公开讨论，只有原作者能合并到上游。

独立修改可以合并；同一内容被双方改动、删除与编辑冲突等情况会停止合并。目前没有网页冲突编辑器，需要先在 Fork 中调整、保存新版本，再更新提案。相关库被删除后，贡献和合并操作也会停止。

## 可见性、删除与永久清理

拥有者可以在“对话库设置”切换公开或私有，变更会作用于**全部历史版本**。公开转私有不能收回别人已经下载或 Fork 的内容。私有来源只能由拥有者 Fork 成私有副本。

“删除”会撤销网站访问，但底层数据仍保留。需要清理数据时，在设置中选择“永久清理此库”，输入库 ID 确认；它会删除该库的版本、草稿、相关贡献记录和独占文件，网站内不能撤销。其他库或 Fork 仍需要的共享内容，以及独立运维备份，会保留。

公开前请检查内容。平台的脱敏和文件排除不能识别所有秘密，来源标记也不等于模型真实性认证。源码的 MIT 许可不自动适用于用户上传的对话。
