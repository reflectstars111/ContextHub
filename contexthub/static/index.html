终端操作示例

在对话工作区保存当前对话与干净的代码提交：

ctx checkpoint --code /path/to/code -m "记录当前实现"

先登录并克隆页面所选版本，再用本机代码仓库恢复到新目录。请替换代码路径与 NEWDIR：

ctx restore REF --code /path/to/code --to NEWDIR

命令创建恢复副本。加上 --codex 可继续导入本机 Codex；多段对话时用 --conversation ID 选择一段。导入结果以本地回执为准。
